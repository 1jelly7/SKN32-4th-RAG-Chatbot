### Decisions
- 현 전환 단계에서는 Agent가 provider를 직접 호출하지 않고 `InProcessMCPPort`를 통해 같은 프로세스의 Tool service를 호출한다. 원격 transport 도입 전까지 비동기 Tool 계약을 유지한다.
- 세션 원문은 cache key material에 넣지 않고 결정적 해시만 사용한다.
- low-confidence evidence는 contradiction으로 취급하지 않으며, contradiction은 명시적 반증 또는 같은 fact의 상이한 값에만 사용한다.
- 공식 backend Tool 경계는 `mcp_servers/document_tools/`와 `mcp_servers/data_tools/`로 한정한다. 중복 `document/`와 `data/` 패키지는 계약 확정 전까지 실험 스켈레톤으로 보존한다.
- 트레이드오프: same-process port는 현재 실행 가능성을 확보하지만 원격 MCP transport·격리·운영 수명주기 검증을 대체하지 않는다.

- fake 기반 chat integration은 API→Graph→MCP 계약을 검증하지만 실제 원격 서비스 연결 완료를 증명하지 않는다.
