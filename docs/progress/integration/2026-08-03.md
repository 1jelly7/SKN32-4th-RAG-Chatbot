### Decisions

- 개발 환경에서 UI 반영 확인을 우선해 정적 UI 자산에 캐시 금지 헤더를 적용했다. 운영 배포에서는 콘텐츠 해시 기반 정적 자산 캐시 전략을 별도로 검토한다.
- 외부 CDN 아이콘 대신 인라인 SVG를 사용해 네트워크·폰트 로딩 여부와 무관하게 핵심 아이콘을 표시한다.
- 임의 HTML을 허용하지 않고, 응답 서식은 굵은 글씨와 줄바꿈만 안전하게 변환한다.
