- `django_app/web/static/web/chat.js`에서 Content-Type을 확인한 뒤 JSON을 파싱하도록 하여 gateway HTML 오류가 JSON 파싱 예외로 노출되지 않게 했다.
- 예열 비차단 및 HTML 응답 방어 회귀 테스트를 추가했다.

### Decisions

- 모델 예열을 startup 완료 전에 동기 대기하지 않고 백그라운드에서 수행한다. API를 먼저 열어 gateway 연결 거부를 막는 대신, 예열 직후 첫 요청은 모델 로딩 비용을 일부 부담할 수 있다.
- 기존 768차원 인덱스와 SBERT 설정은 정합성이 확인됐으므로 재인덱싱하지 않는다.
- gateway가 반환하는 HTML 오류를 API 성공으로 간주하지 않도록 UI에서 Content-Type을 검사하되, backend 장애 자체는 서버 로그와 상태 코드로 계속 구분한다.
