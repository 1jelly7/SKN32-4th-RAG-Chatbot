### Goal

- 분리 계획, 정본 계약, 구현을 다시 대조해 책임 누수와 운영 전환 결함을 수정한다.

### Findings and Changes

- `account_db`가 FastAPI/MCP의 `allowed_databases`에 남아 있던 책임 누수를 제거했다.
  계정 DB는 Django만 소유하며 admin/hr 사용자 컨텍스트에도 업무 DB 권한으로 노출하지 않는다.
- Django의 상대 `STATIC_URL`과 FastAPI `/static` 충돌을 제거했다. Admin asset은
  `/django-static/*`의 `collectstatic` 산출물로 제공하도록 경로 계약을 분리했다.
- `createsuperuser`가 `display_name`과 `role` 없이 잘못된 계정을 만들 수 있던 구성을
  `REQUIRED_FIELDS`로 보완했다. 애플리케이션 admin 역할과 Django staff 권한 분리는 유지한다.
- legacy migration이 임의 scrypt 파라미터·잘못된 필드를 그대로 받아들이고 naive
  `DATETIME`을 UTC로 단정하던 문제를 수정했다. 고정 해시 형식과 필드 범위를 검증하고
  `LEGACY_ACCOUNT_TIME_ZONE`을 적용하며, 위험한 부분 rollback 대신 irreversible migration으로 표시했다.
- 이관 감사에 `created_at/date_joined` 비교를 추가하고, 인증 트래픽 전에 실행해야 하는
  순서를 README와 계획에 명시했다.
- FastAPI 내부 인증 HTTP client가 환경 proxy를 사용하지 않게 하고 성공 응답 타입과
  opaque session ID 형식을 엄격히 검증하도록 보완했다.
- 로그인 입력 타입·크기를 엄격히 검증하고, UI가 logout 실패를 성공으로 표시하지 않도록 수정했다.
- 오래된 단일 FastAPI 실행법과 실제로 없는 API를 설명하던 README를 현재 이중 서비스
  실행·migration·경로 라우팅 절차로 교체했다.
- rollback은 현 코드에서 legacy 라우터를 켜는 방식이 아니라, 보존 DB와 검증된 이전
  배포 버전으로 되돌리는 방식임을 계획에 명시했다.
- 관찰 중 Django 계정 변경으로 legacy snapshot과 계정 집합·역할·비밀번호가 달라지는
  것을 막기 위해 Admin 계정 추가·삭제와 이관 계정 변경을 기본 잠금했다.

### Verification

- pytest, Django system check, migration check, 서버·브라우저 실행은 수행하지 않았다.

### Cause and fix

- `scripts/local_gateway.ps1`이 BOM 없는 UTF-8이어서 Windows PowerShell 5.1이 시스템 ANSI
  코드페이지로 해석했고, 한글 상태 문자열이 깨지면서 문자열 종결자 ParserError가
  발생했다.
- launcher 내부 문자열을 ASCII로 제한해 BOM이나 시스템 코드페이지와 무관하게
  PowerShell 5.1과 PowerShell 7에서 동일하게 파싱되도록 수정했다.
- 시작 시 해석한 `nginx.exe` 절대경로를 runtime 상태에 저장해, 이후 별도 PowerShell의
  PATH에서 Nginx를 찾지 못해도 `stop`과 `restart`가 같은 실행 파일을 사용하도록 했다.

### Verification

- Windows PowerShell `5.1.26100.9168`에서 ParserError 없이 `status` 실행.
- PowerShell 5.1에서 launcher 전체 `start`, Nginx 설정 검사와 세 서비스 기동 확인.
- gateway UI·health·CSS `200`, 내부 introspection `404` 확인.
- Nginx 경로를 PATH에 추가하지 않은 별도 PowerShell 5.1 프로세스에서 `stop` 성공.
- 종료 후 Django/FastAPI/Nginx 상태가 모두 `stopped`이고 `8000`·`8001`·`8002` listen
  socket이 남지 않음을 확인.
