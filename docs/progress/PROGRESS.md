## 활성 작업 및 제약

- 로컬 서버는 반드시 `skn_3rd` 가상환경의 Python으로 실행한다. 기본 Anaconda Python은 FastAPI 의존성을 포함하지 않을 수 있다.
- 문서 검색의 실제 무결과 응답은 현재 개발용 코퍼스에서 재현하지 못했다. 초기 빈 상태와 코드 경로는 확인했지만, 데이터 기반 재검증이 남아 있다.
- 표·차트 응답은 이번 실제 질의에서 발생하지 않아 해당 UI의 시각 회귀는 미검증이다.
- 운영 환경의 장기 캐시 전략은 개발용 `no-store`와 분리해 결정한다.

## 주요 결정
