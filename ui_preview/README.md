# ui_preview

UI 시안 보관 폴더. 실제 코드를 고치기 전에 여기서 먼저 만들어 검토한다.

## 규칙

- 파일명: `<YYYYMMDD>-<화면이름>.html` (예: `20260825-chat-redesign.html`)
- Django 템플릿 태그(`{% static %}`, `{% load %}`)를 쓰지 않는다.
  브라우저에서 파일을 바로 열어도 렌더되는 **단일 HTML**로 만든다.
- CSS와 더미 데이터를 파일 안에 인라인한다. 색·간격 토큰은 실제 `style.css`의
  `:root` 값을 복사해 시각적으로 동일하게 맞춘다.
- 기본 / 로딩 / 빈 상태 / 오류 / 긴 텍스트 상태를 함께 보여준다.
- 방향이 갈리면 안(案)별로 파일을 나누고, 파일명 뒤에 `-a`, `-b`를 붙인다.
- 승인 후 `django_app/web/`으로 이식하며, 시안 파일은 이력으로 남긴다.

## 보는 방법

시안은 정적 파일이라 Django 서버 없이 열린다. 브라우저에서 직접 열거나,
간단히 로컬 서버로 띄운다.

```bash
python -m http.server 8800 --directory ui_preview
```
